# Готовая Windows-сборка

[Скачать Forma 1.8.0 для Windows x64](https://github.com/Astronomial/music/raw/refs/heads/main/downloads/Forma-1.8.0-Windows-x64.exe)

Сохрани `.exe` на компьютер и запусти. Установка и Node.js не нужны. Это portable-сборка для Windows 10/11 x64. Подробности запуска и ограничения проверки приведены в основном [README](../README.md).

Сборка не подписана сертификатом издателя. SHA-256 находится в [SHA256SUMS.txt](SHA256SUMS.txt).

Для iPhone: [IPA и установка с Windows](../ios/INSTALL_WINDOWS.md). Для обмена через интернет настрой один Google-аккаунт на обеих платформах: [инструкция Google Cloud](../docs/GOOGLE_SYNC.md). Общая Wi-Fi сеть не нужна.
