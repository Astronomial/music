# Готовая Windows-сборка

[Скачать Forma 1.15.3 для Windows x64](https://github.com/Astronomial/music/releases/download/win-v1.15.3/Forma-1.15.3-Windows-x64.exe)

Сохрани `.exe` на компьютер и запусти. Установка и Node.js не нужны. Это portable-сборка для Windows 10/11 x64. Подробности запуска и ограничения проверки приведены в основном [README](../README.md).

Сборка не подписана сертификатом издателя. SHA-256 находится в [манифесте релиза](https://github.com/Astronomial/music/releases/download/win-v1.15.3/Forma-Windows-SHA256SUMS.txt).

Для iPhone: [IPA и установка с Windows](../ios/INSTALL_WINDOWS.md). Библиотека передаётся по домашней сети только после просмотра и подтверждения пакета на ПК или телефоне: [инструкция](../docs/WIFI_SYNC.md). Google-аккаунт не нужен.
