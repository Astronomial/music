Forma 1.15.4 для Windows 10/11 x64 — исправление NO_AUDIO_FORMAT.

- Аудиоформаты без необязательных полей качества больше не отбрасываются. Проверяются оба списка форматов YouTube.
- Добавлен резервный аудиопуть HLS: поток разбирается и воспроизводится через MediaSource без видео. Поддержаны перемотка, фон и переключение обратно на обычный поток/локальный файл.
- Ошибка сохраняет результаты всех клиентов; версия Forma и последняя ошибка доступны в настройках.
- Перед публикацией выполнены проверки исходников и запуска собранного Windows EXE с его app.asar. Сетевая часть проверяется настоящим Chromium через контролируемый HTTP-сервер; живой YouTube блокируется политикой среды разработки.

Полностью закрой прежнюю Forma и запусти новый EXE. В настройках должно быть «Forma 1.15.4». Библиотека сохраняется, перенос вручную не требуется.
