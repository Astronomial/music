Forma 1.18.0 — вся коллекция лайков и пополняемые подборки.

- Знакомые 30% Пульса выбираются из всех лайков: случайный порядок без закрепления одних и тех же песен наверху. Ротация сохраняется после перезапуска и подтверждённой синхронизации.
- Подборки рассчитаны на 25 подходящих треков; дополнительные записи ищутся по настроению, после конца списка подбор продолжается. Противоречащие настроению песни не добавляются ради количества.
- Новые записи знакомых артистов и близкие новые исполнители участвуют в открытиях. Источники поиска перебираются за пределами прежнего узкого набора.
- Локальная модель отдельно учится по жанру, исполнителю, настроению и звучанию. Старое обучение сохраняется. Один сохранённый фоновый микс больше не разрешает все похожие функциональные загрузки.
- Библиотека, аудиоплеер, фоновое воспроизведение и обмен по Wi-Fi с подтверждением сохранены.

Для того же поведения на iPhone установи Forma iOS 1.10.0. Описание алгоритма и ограничений, воспроизводимый прогон: docs/PULSE_1_18_0.md.
