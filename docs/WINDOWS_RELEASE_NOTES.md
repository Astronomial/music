Forma 1.17.1 — надёжнее подключение iPhone и ПК.

- Ethernet и Wi-Fi получают приоритет перед VPN/виртуальными адаптерами; доступен ручной выбор сети.
- Сервер принимает соединения на доступных локальных интерфейсах; код содержит до восьми адресов, iPhone выбирает доступный с правильным сертификатом.
- Смена IP и включение сети после запуска сохраняют идентичность ПК и ожидающие подтверждения пакеты.
- Параллельное включение и повтор после потерянного ответа подключения обработаны без расходования второго кода.
- Добавлены копирование кода и разрешение порта в брандмауэре: только TCP, локальная подсеть и частные сети. Права администратора запрашиваются Windows только по нажатию кнопки.
- Библиотека переносится после просмотра и подтверждения на одном устройстве. Рекомендации и аудиоплеер не менялись.

Обнови iPhone до Forma iOS 1.9.2. ПК подключи к роутеру по Ethernet или Wi-Fi, iPhone — к Wi-Fi этого роутера. USB-кабель не является каналом обмена Forma.
