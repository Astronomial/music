Forma 1.15.5 для Windows 10/11 x64 — резерв воспроизведения через веб-плеер YouTube.

В 1.15.0 штатный браузерный плеер был заменён самописным получением прямых аудиоссылок. Теперь при отказе этого пути или ожидании дольше шести секунд музыка запускается обычным веб-плеером в отдельном невидимом окне. Видеопанель не возвращается; резерв может загружать видео в фоне. После успешного запуска следующие треки используют готовый браузерный контекст.

Работают пауза, продолжение, громкость, перемотка, автоматический следующий трек, сворачивание и возврат к локальной музыке. Старый источник останавливается; закрытие приложения завершает фоновый процесс. Проверки выполняются также из упакованного Windows EXE. Доступ к живому YouTube среда разработки блокирует; для проверки механики использована контролируемая страница с настоящим аудиопотоком.

Закрой прежнюю Forma и запусти новый EXE. В настройках должна быть версия 1.15.5. Библиотека сохраняется.
