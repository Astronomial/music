Forma 1.19.2 — исправления аудита рекомендаций.

Скрытые треки больше не усиливают положительный профиль вкуса. Сохранённые записи заблокированных исполнителей и исключённых направлений перестают служить положительными источниками рекомендаций.

Сохраняются поиск свежих релизов, обучение по реакциям, ротация всех лайков и сохранённых плейлистов, фон, очередь и подтверждённый обмен по Wi-Fi. Установленная библиотека сохраняется при запуске под прежним профилем Windows.

Проверки: регрессия на скрытые/заблокированные источники, полный JavaScript-набор, восемь сценариев интерфейса, нативные проверки Electron и повторное воспроизведение из собранного Windows-приложения. Аудит и исправления: https://github.com/Astronomial/music/pull/1.
