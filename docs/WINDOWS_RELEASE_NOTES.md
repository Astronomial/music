Forma 1.17.0 — рекомендации по вкусу и подтверждённым жанрам.

- Общие результаты вроде «energetic music» и «музыка для…» больше не заменяют песни из любимых; случайное дослушивание не обучает Пульс на них. Явно сохранённая фоновая музыка поддерживается.
- Жанр поискового запроса больше не считается жанром записи и не обучает профиль вкуса. Накопленные поисковые метки не влияют на жанровые предпочтения.
- Перед разнообразием, языком и новизной проверяется музыкальная связь с библиотекой. Неподходящие жанры и случайные песни не заполняют свободные места в подборках.
- Добавлена фоновая сверка жанров с публичным каталогом Apple iTunes: точное название, исполнитель, длительность; ремиксы и каверы не получают жанр оригинала. Сомнительное совпадение остаётся неизвестным.
- Звучание по существующему аудиопрофилю помогает ранжированию. Оно не превращается в выдуманную точную жанровую метку.
- Дизлайки исключены из автоматических рекомендаций. Сохраняются близкие новые исполнители, русскоязычный приоритет, история и библиотека.
- Новая сверка работает отдельно от загрузки аудио и не блокирует воспроизведение. Музыкальные файлы в Apple не отправляются; запрос содержит исполнителя и название.

Полностью закрой прежнюю Forma и запусти новый EXE. Библиотеку удалять не нужно.
