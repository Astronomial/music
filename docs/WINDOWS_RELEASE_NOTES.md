Forma 1.15.3 для Windows 10/11 x64 — исправление воспроизведения 1.15.0–1.15.1.

- Исправлены получение и обработка аудиоссылок YouTube. Используется основной аудиоклиент, как на iOS, с проверкой начала потока до выбора источника.
- Обрабатываются подписи, параметры медиазапросов и безопасные перенаправления серверов Google Video. Исправлены блокирующий заголовок и обработка перенаправлений в сетевом транспорте Electron.
- Исправлена передача диапазонов байтов для запуска и перемотки. Ошибки больше не сводятся только к общему сообщению о недоступном треке.
- Сохранены аудио без видео, новый интерфейс, порядок любимых и более частые падающие звёзды. Библиотека, локальные файлы и Wi-Fi обмен сохраняются.

Полностью закрой прежнюю Forma и запусти новый EXE. Переносить библиотеку вручную не нужно. Проверки используют настоящий Electron и AAC с контролируемыми ответами серверов; доступность живого YouTube на пользовательском подключении проверяется отдельно.
