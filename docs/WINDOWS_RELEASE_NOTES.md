Forma 1.15.0 для Windows 10/11 x64.

- Убраны правая панель с видео, статус «На связи» и пункт настройки Пульса слева. Настроить Пульс можно под галактикой.
- YouTube теперь воспроизводится только как аудио: без видео и iframe, с прежней нижней панелью управления. Ссылки следующих трёх треков готовятся заранее.
- Audius удалён. Скачанные ранее файлы и библиотека сохраняются.
- Недавно добавленные любимые треки находятся сверху.
- Падающие звёзды появляются вчетверо чаще. Уменьшение движения учитывается.

Скачай EXE и запусти. Portable-сборка использует прежний профиль, переносить библиотеку вручную не нужно. Неофициальный аудиопуть зависит от доступности YouTube; локальная музыка работает без него. Доступ к живому YouTube проверяется на пользовательском подключении, отдельно от контролируемых автотестов.
