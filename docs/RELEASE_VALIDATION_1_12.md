# Windows 1.12.0 — космическая тема

Фиолетово-чёрный фон, редкие падающие звёзды, мерцание и собственная спиральная галактика Пульса. Цвета подборок, панели и плеер согласованы с темой. Палитры и размер текста сохранены; первая палитра теперь называется «Космос» с прежним внутренним ID `iris`. Файлы iOS не менялись.

## Реализация и движение

Два локальных SVG создаются воспроизводимо командой `node scripts/generate-cosmos-art.mjs`. Изображение галактики статично; вращается один слой. Движение звёзд использует CSS transform/opacity. Нет видеофона, WebGL, сторонних ресурсов или JavaScript-цикла отрисовки частиц. Декоративные слои не перехватывают мышь и скрыты от средств чтения экрана.

В настройках «Цвет и свет» выключатель «Движение звёзд» сохраняет локальное предпочтение. Учитывается `prefers-reduced-motion`; при уменьшении движения метеоры скрыты и галактика статична. В скрытом окне эффекты приостанавливаются, а за пределами видимой области приостанавливается галактика. Аудиоплеер сохраняет работу и не пересоздаётся из-за смены видимости.

## Проверки

- 134/134 теста Node пройдены.
- Пять сценариев Chromium пройдены. Дополнительно проверены сохранение выключателя после перезапуска, уменьшение движения, пауза галактики в скрытом документе и продолжающееся воспроизведение при том же экземпляре YouTube-плеера.
- Настоящий Electron в Linux: sandbox/preload, нативный AAC, локальное аудио при сворачивании, управляемый YouTube-плеер, пауза, сохранение, импорт, офлайн, просмотр/подтверждение Wi-Fi обмена пройдены.
- Главная проверена при 1920×1080. При открытой YouTube-панели и максимальном масштабе текста проверены 1000, 1280, 1440 и 1920 px: горизонтального переполнения нет; кнопки Пульса остаются внутри карточки.
- Просмотрены скриншоты [главной](../artifacts/forma-cosmos.png), настроек и YouTube. Музыкальные записи и iframe в этих сценариях контролируемые, не живой сервис.
- Одно сравнение idle-страницы в headless Chromium, по 3 секунды с включёнными/выключенными эффектами: TaskDuration 8,70 / 2,35 мс, LayoutDuration 0 / 0 мс, RecalcStyleDuration 1,54 / 0 мс. Это счётчики главного потока конкретного запуска, не замер GPU, FPS или гарантия нагрузки на любом Windows-ПК.
