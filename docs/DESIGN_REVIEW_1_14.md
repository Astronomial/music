# Проверка дизайна Windows 1.14.0

Критерии взяты из [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), прочитанного в этой беседе. [Основная композиция и палитра](DESIGN_COSMOS.md) сохраняются: выразительная галактика, фиолетово-чёрный фон и спокойные полупрозрачные поверхности. Изменения предназначены для Windows.

| Критерий | Что проверено и изменено |
| --- | --- |
| Один главный акцент | Декоративный значок в заголовке настройки Пульса убран, чтобы не пересекаться с закрытием. Разделы получили отдельные интервалы. Галактика Пульса остаётся центром главной. Компактная навигация освобождает место, не добавляя декоративных панелей. |
| Тексты помогают действовать | Убраны оставшиеся декоративные подписи и прописные заголовки. Пустая подборка и ошибка источника отличаются от загрузки. |
| Типографика и иерархия | Один системный шрифт с поддержкой кириллицы, сохранён масштаб текста. Исправлены пропуски уровней заголовков и названия областей экрана. |
| Понятная навигация | Кнопка сворачивания рядом с логотипом, обратное действие на том же месте. Подсказки, доступные названия, выбранный раздел, плейлисты и настройки работают в обоих режимах. Режим хранится в профиле ПК, не передаётся на iOS. |
| Клавиатура и фокус | Кнопки сохраняют действие пробела; диалоги получают фокус, пропускают скрытые элементы, возвращают фокус после закрытия. Остальная часть окна становится inert, музыка продолжает играть. |
| Последовательность действий | «Назад» восстанавливает запрос; со страницы артиста возвращает в поиск. Esc закрывает очередь; выбор трека в очереди продолжает её с этого места. |
| Умеренное движение | Звёзды и галактика сохранены. Сворачивание панели реагирует сразу, без отдельной анимации перетекания всей сетки. Системное уменьшение движения учитывается. |
| Устойчивые состояния | У изображений есть запасной вид. Ошибка чтения библиотеки показывает восстановление и не запускает сохранение пустого профиля. |

## Проверка в браузере

Проверяется собранная веб-версия с контролируемым каталогом и плеером. Для аудита используется axe-core 4.10.3, загруженный только в проверочный браузер; новых зависимостей приложения нет. Автоматическая проверка дополняется скриншотами, обходом клавиатурой и проверкой геометрии: она не доказывает доступность всех сочетаний данных и не заменяет проверку человеком с экранным диктором.

Проверяются главная, пустой поиск, результаты, артист, любимое, скачанное, перенос, общие настройки, настройка Пульса, создание плейлиста, подборка, очередь, меню трека, добавление в плейлист, переименование, удаление, сброс истории, отсутствие результатов, ошибка источника, знакомство и восстановление библиотеки. Каждый тип экрана просматривается с обычной и компактной панелью. Управление отдельно проверяется при ширине 600–1920 px и максимальном размере текста.

Итоги автоматического прохода и сборки — в [проверке выпуска](RELEASE_VALIDATION_1_14.md). Скриншот компактной панели: [forma-sidebar-compact.png](../artifacts/forma-sidebar-compact.png).
