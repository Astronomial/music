# Космос Forma · Windows 1.13

Применён [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): прочитан 14 октября 2026, затем выполнен второй проход по иерархии, подписям и скриншотам. Отдельный плагин не устанавливался. Эта итерация затрагивает только Windows.

## Направление и токены

Главная задача экрана — запустить персональную музыку. Галактика становится самостоятельным центром экрана; фон со звёздами объединяет навигацию, контент и плеер. Текст объясняет действие, а не украшает экран.

- Глубокий фон: `#050309`.
- Основа прозрачных поверхностей: `#100a1a`, непрозрачность около 60%.
- Туманность: `#5e2098`, низкая непрозрачность.
- Акцент: `#c4b5fd`; существующие пользовательские палитры сохраняются.
- Основной текст: `#f6efff`.
- Вторичный текст: `#bdb0cf`.

Шрифт — Segoe UI Variable / Segoe UI для Windows, Arial как резерв. Один шрифт, заголовок Пульса 36 px, подборки 25 px, действие запуска 18 px, вторичные действия 14 px. Масштаб текста пользователя сохраняется. Заголовки и управление Пульсом выровнены по центру, списки и названия подборок — по левому краю.

```text
Навигация | Поиск
          |              Пульс
          |            галактика
          |          Слушать Пульс
          |             Настроить
          | По настроению
          | [подборка] [подборка] [подборка]
          | Тебе может понравиться
----------------- плеер -----------------
```

## Критика и второй проход

Первоначальные приветствие, маркетинговый абзац, прямоугольный герой и три названия каждой подборки создавали лишнюю иерархию. Удалены баннер и приветствие, декоративные надписи над заголовками и нумерация настроек. У каждой подборки оставлено одно название; артист и число треков помогают выбрать музыку. Часть пояснений сохранена: ограничения источника, условия импорта и подтверждение Wi-Fi обмена влияют на решение пользователя.

Один главный выразительный элемент — галактика. Метеоры — тонкие белые шлейфы длиной 84–125 px, примерно один каждые четыре секунды. Существующая галактика не заменена тяжёлым Canvas/WebGL или видео. Анимации используют transform/opacity, не перехватывают клики, при скрытии документа приостанавливаются, учитывают системное уменьшение движения и выключатель в настройках.

## Референсы

- [Grok](https://grok.com): текстовая версия доступна; живую анимацию в средстве просмотра подтвердить нельзя.
- [Публичный Grok-inspired starfield](https://github.com/UsmanDevCraft/grok-shooting-stars) и [описание эффекта](https://dev.to/usman_awan/how-i-built-a-grok-inspired-starfield-shooting-stars-using-html-canvas-3872): ориентир для редких белых метеоров. Код в приложение не копировался; реализация собственная, на CSS.
- [Новая веб-версия Яндекс Музыки](https://yandex.ru/company/news/03-26-03-2025), [Моя волна](https://yandex.ru/project/music/myvibe/): ориентир для центрального персонального запуска. В Forma используется собственная галактика и явно запрошенная композиция без прямоугольной карточки.
