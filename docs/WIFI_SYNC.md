# Обмен между Windows и iPhone по Wi-Fi

Нужны **Forma Windows 1.9.0 и iOS 1.3.0**. Google-аккаунт и Google Cloud больше не используются. Библиотека на каждом устройстве сохраняется сразу; перенос изменений требует отдельного подтверждения каждого пакета **на любом одном устройстве**.

## Подключение

1. Подключи iPhone к домашнему Wi-Fi, ПК — к этому же роутеру по Wi-Fi или Ethernet. Открой Forma на обоих устройствах.
2. На ПК: **Настройки → iPhone и ПК · Wi-Fi → Подключить iPhone**. При запросе брандмауэра разреши Forma доступ к **частным сетям**.
3. На iPhone: **Настройки → Синхронизация с ПК**, вставь код из Forma на ПК и нажми **Подключить ПК**. Разреши доступ к локальной сети iOS. Код действует пять минут и используется один раз; новый код можно получить на ПК.
4. Подключение подготовит первый пакет. Просмотри разделы **На ПК** и **На iPhone**: лайки, дизлайки, плейлисты, история, настройки и признаки звучания. Подключение само по себе библиотеку не меняет.
5. Нажми **Применить на обоих устройствах** на ПК **или** iPhone. Второе подтверждение не нужно. ПК сохраняет решение, телефон получает его по Wi-Fi. **Отклонить обмен** оставляет обе библиотеки без переноса.

При следующих изменениях открой настройки телефона и нажми **Подготовить обмен**. Автоматически проверяется только решение по уже подготовленному пакету; новые изменения без нового просмотра и подтверждения не переносятся. Если ПК подтвердил обмен, пока телефон недоступен, получение продолжится при следующем подключении. Повторный запрос не применяет тот же пакет дважды.

## Что переносится

YouTube-метаданные, плейлисты, лайки, дизлайки, скрытые треки, история с контекстом рекомендаций, настройки Пульса и числовые признаки звучания. Локальные аудиофайлы, пути, ключи, громкость и оформление остаются на устройстве. Изменения, внесённые на телефоне во время ожидания, сохраняются при объединении; для передачи этих новых правок нужен следующий пакет.

Просмотр действует 15 минут. Если библиотека ПК изменилась после подготовки, приложение отклонит устаревшее подтверждение: проверь состояние на iPhone и подготовь новый пакет. Это предотвращает применение изменений, отличающихся от просмотренных. Одобренный пакет хранится на ПК до получения телефоном, не дольше суток; если телефон долго отсутствовал, подготовь обмен заново.

Соединение защищено TLS с закреплённым сертификатом ПК и токеном конкретного телефона. Отключение всех телефонов на ПК отзывает подключения. Прежние Google-реквизиты на устройстве удаляются при обновлении; файлы в Google Drive приложение не изменяет. Старые версии протокола автоматического обмена отклоняются: обнови обе платформы.

## Если не подключается

- ПК и iPhone должны находиться в одной локальной сети; гостевая сеть или изоляция клиентов роутера могут мешать.
- В Windows открой **Параметры → Сеть и Интернет → Ethernet/Wi-Fi → свойства текущего подключения → Частная сеть** для своей домашней сети. Разреши Forma в брандмауэре; выключать брандмауэр не нужно.
- На iPhone разрешение доступно в **Настройки → Конфиденциальность и безопасность → Локальная сеть → Forma**.
- VPN можно оставлять включённым. Его настройки должны разрешать доступ к локальной сети. Код содержит текущий локальный адрес ПК; после изменения адреса подключи телефон новым кодом.
- Обмен не выполняется через мобильную сеть. Прослушивание музыки и подготовка следующих треков работают независимо от подключения к ПК.
