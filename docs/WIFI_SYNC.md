# Обмен между Windows и iPhone по Wi-Fi

Для исправленного подключения обнови обе версии: **Forma Windows 1.19.1 и iOS 1.11.1**. Google-аккаунт и Google Cloud больше не используются. Библиотека на каждом устройстве сохраняется сразу; перенос изменений требует отдельного подтверждения каждого пакета **на любом одном устройстве**.

## Подключение

1. Подключи iPhone к домашнему Wi-Fi, ПК — к этому же роутеру по Wi-Fi или Ethernet. Открой Forma на обоих устройствах.
2. На ПК: **Настройки → iPhone и ПК · Wi-Fi → Подключить iPhone**. Выбери адрес **Ethernet** или **Wi-Fi**, если показано несколько адаптеров. VPN и виртуальные сети автоматически стоят ниже обычных. Нажми **Разрешить обмен в брандмауэре** и подтверди запрос Windows: правило действует только на порт обмена TCP из локальной подсети в частных сетях. **Скопировать код** копирует полный код подключения.
3. На iPhone: **Настройки → Синхронизация с ПК**, вставь код из Forma на ПК. Кнопка **Проверить соединение** проверяет доступность адресов и сертификат без переноса библиотеки. Затем нажми **Подключить ПК**. Разреши доступ к локальной сети iOS. Код действует пять минут и используется один раз; новый код можно получить на ПК.
4. Подключение подготовит первый пакет. Просмотри разделы **На ПК** и **На iPhone**: лайки, дизлайки, плейлисты, история, настройки и признаки звучания. Подключение само по себе библиотеку не меняет.
5. Нажми **Применить на обоих устройствах** на ПК **или** iPhone. Второе подтверждение не нужно. ПК сохраняет решение, телефон получает его по Wi-Fi. **Отклонить обмен** оставляет обе библиотеки без переноса.

При следующих изменениях открой настройки телефона и нажми **Подготовить обмен**. Автоматически проверяется только решение по уже подготовленному пакету; новые изменения без нового просмотра и подтверждения не переносятся. Если ПК подтвердил обмен, пока телефон недоступен, получение продолжится при следующем подключении. Повторный запрос не применяет тот же пакет дважды.

## Ethernet, USB и VPN

ПК по Ethernet и iPhone по Wi-Fi одного роутера поддерживаются. USB может оставаться подключённым, но не является транспортом этого обмена: отключение Wi-Fi телефона не заменяется одним USB-кабелем.

Код содержит до восьми локальных IPv4-адресов. iPhone параллельно проверяет доступность и закреплённый сертификат, выбирает рабочий адрес и сохраняет его. Обычный интернет-маршрут через VPN/мобильную сеть не отменяет доступную LAN. Сеанс обмена запрещает cellular и не использует системный HTTP-прокси; VPN-маршрутизацию и его запрет локальной сети приложение не отменяет.

Идентичность ПК теперь постоянна при смене IP или адаптера. Если старые адреса больше не работают после DHCP/смены роутера, вставь свежий код с того же ПК. Действующий токен и ожидающий обмен сохраняются. Если телефон был отозван на ПК, нужен новый одноразовый код. Сеть появилась после запуска ПК — код обновится в настройках без перезапуска сервера.

## Что переносится

YouTube-метаданные, плейлисты, лайки, дизлайки, скрытые треки, история с контекстом рекомендаций, настройки Пульса и числовые признаки звучания. Локальные аудиофайлы, пути, ключи, громкость и оформление остаются на устройстве. Изменения, внесённые на телефоне во время ожидания, сохраняются при объединении; для передачи этих новых правок нужен следующий пакет.

Просмотр действует 15 минут. Если библиотека ПК изменилась после подготовки, приложение отклонит устаревшее подтверждение: проверь состояние на iPhone и подготовь новый пакет. Это предотвращает применение изменений, отличающихся от просмотренных. Одобренный пакет хранится на ПК до получения телефоном, не дольше суток; если телефон долго отсутствовал, подготовь обмен заново.

Соединение защищено TLS с закреплённым сертификатом ПК и токеном конкретного телефона. Отключение всех телефонов на ПК отзывает подключения. Прежние Google-реквизиты на устройстве удаляются при обновлении; файлы в Google Drive приложение не изменяет. Старые версии протокола автоматического обмена отклоняются: обнови обе платформы.

## Если не подключается

- ПК и iPhone должны находиться в одной локальной сети; гостевая сеть или изоляция клиентов роутера могут мешать.
- В Windows открой **Параметры → Сеть и Интернет → Ethernet/Wi-Fi → свойства текущего подключения → Частная сеть** для своей домашней сети. Правило Forma действует в частных сетях: если домашний Ethernet отмечен как общедоступный, сначала выбери «Частная сеть», затем нажми разрешение обмена в Forma. Выключать брандмауэр не нужно.
- На iPhone разрешение доступно в **Настройки → Конфиденциальность и безопасность → Локальная сеть → Forma**.
- VPN можно оставлять включённым. Его настройки должны разрешать доступ к локальной сети. После смены подсети можно вставить свежий код; действующее подключение к тому же ПК восстанавливается без сброса библиотеки.
- На iPhone открой **Если ПК недоступен → Открыть настройки iPhone** и проверь разрешение локальной сети. Подробная ошибка остаётся в строке состояния. Проверка соединения не применяет изменения.
- Обмен не выполняется через мобильную сеть. Прослушивание музыки и подготовка следующих треков работают независимо от подключения к ПК.

## Проверено в выпуске

Локальные проверки включают настоящий HTTPS/TLS-сервер, смену адреса и восстановление токена/ожидающего пакета, параллельное включение, повтор потерянного ответа подключения, границы локальных адресов и ограничение правила брандмауэра. Проверка интерфейса меняет сетевой адаптер и вызывает разрешение брандмауэра только по нажатию.

Нативный iOS-сценарий начинает с недоступного основного адреса, подключается по запасному с правильным сертификатом, отклоняет чужой сертификат и повторно подключается без замены токена или потери подготовленного пакета. Затем проверяет одобренный двусторонний обмен и воспроизведение в фоне. Физический роутер, iPhone пользователя и его VPN из среды разработки недоступны. Запрос UAC тестовым сценарием не подтверждается: проверяется ограниченный скрипт правила, применение выполняется на ПК пользователя по его нажатию.
