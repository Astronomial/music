# Исправление подключения Windows 1.17.1 / iOS 1.9.2

Проверяемая схема пользователя: Windows по Ethernet, iPhone по Wi-Fi того же роутера; USB также подключён. USB не является транспортом обмена библиотеки Forma.

## Найденные причины

| Было | Стало |
| --- | --- |
| Первый IPv4 из `os.networkInterfaces`, включая VPN/виртуальные адаптеры | Известные VPN/виртуальные адаптеры ниже обычных, ручной выбор и до восьми адресов в коде |
| TLS-сервер привязан к одному выбранному адресу | Прослушивание локальных интерфейсов, проверка частного адреса клиента и токена |
| Смена адреса пересоздаёт сертификат и меняет идентичность ПК | Сертификат установки сохраняется при DHCP/смене адаптера, пока он действителен |
| Кнопки iOS блокируются интернет-маршрутом cellular, даже при доступной LAN | Отдельный LAN-монитор/успешная проверка ПК; URLSession запрещает cellular |
| Повтор подключения создаёт новый токен и сбрасывает ожидающий обмен | Проверка старого токена того же ПК; действующая связь и пакет сохраняются |
| Потеря ответа на одноразовый код требует нового кода | Повтор с тем же requestID получает исходный результат в течение минуты |
| Ошибка обмена скрывается за общей фразой | Проверка соединения, локальный адрес и подробная ошибка в настройках |

Каждый адрес проверяется по тому же DER-отпечатку сертификата; резервный адрес не означает отключения TLS-проверки. Публичные адреса, дубли параметров и неограниченный список кандидатов отвергаются. Старые одноадресные коды и сохранённые соединения читаются.

## Windows и VPN

В Forma есть кнопка разрешения TCP-порта обмена из LocalSubnet только в профиле Private. Windows показывает UAC лишь по нажатию. Правило не отключает брандмауэр и не открывает публичные сети. Домашний Ethernet должен быть отмечен как частный в параметрах Windows. Сценарий проверяет сформированный скрипт; UAC не подтверждается в CI.

iPhone не использует системный HTTP-прокси для закреплённого локального соединения. Настройки маршрутов VPN, запрет LAN и изоляцию клиентов роутера приложение не меняет. VPN должен разрешать локальную сеть. Физические iPhone/роутер пользователя из среды разработки недоступны.

## Проверки

- Локально 172 Node-теста, включая настоящий HTTPS/TLS с имитацией смены адреса, восстановлением действующего токена и ожидающего пакета, параллельным включением и повтором потерянного ответа подключения.
- Локально 116 тестов Swift FormaCore, включая старый/многоадресный код, границы адресов/числа кандидатов и независимость LAN от интернет-маршрута.
- Браузерная проверка переключает адаптер, проверяет обновление кода и вызов разрешения брандмауэра по кнопке; подтверждение/отклонение остаются обязательными.
- Нативный сценарий iOS сначала использует недоступный основной адрес и доступный резервный, затем переподключается с сохранением токена/подготовленного пакета, подтверждает двусторонний обмен и проверяет фоновое воспроизведение.
- Windows CI дополнительно проверяет настоящее приложение и упакованный EXE с реальным локальным аудио и подтверждаемым TLS-обменом.
