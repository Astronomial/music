# Windows 1.12.1 — значок галактики

Новая фиолетовая галактика заменяет значок файла приложения, окна и ярлыков Windows. Изменены графические ресурсы, версия и документация. Код интерфейса, рекомендаций, воспроизведения и файлы iOS не менялись.

- Исходное изображение: `build/icon-source.png`, сгенерировано специально для Forma.
- PNG окна: `build/icon.png`, 512×512, с прозрачностью.
- Windows ICO: `build/icon.ico`, размеры 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px.
- Проверены уменьшенные варианты. Подготовка PNG/ICO — техническое масштабирование и преобразование формата исходного изображения.
- RT_ICON/RT_GROUP_ICON внутреннего `Forma.exe` прочитаны через resedit: десять кадров новой галактики совпадают с ICO. PNG в `app.asar` побайтно совпадает с `build/icon.png`, версия пакета — 1.12.1.

Окончательная упаковка EXE и контрольная сумма будут проверены перед завершением публикации. Предыдущие проверки космической темы: [Windows 1.12.0](RELEASE_VALIDATION_1_12.md).
