# Forma: синхронизация через Google

Для Windows 1.8.0 и iOS 1.2.0. Нужен обычный Google-аккаунт; подписка, собственный сервер и общий Wi-Fi не требуются. ПК может быть выключен. Оба приложения должны иметь доступ к Google через твою сеть/VPN.

В этой сборке нет встроенных OAuth-реквизитов: нужно один раз создать свой проект. Вход без реальных Client ID не работает. Не присылай пароли Google, refresh token или client secret в чат и не добавляй их в GitHub.

## 1. Создать проект

1. Открой [Google Cloud Console](https://console.cloud.google.com/). Войди в свой Google-аккаунт.
2. В верхней панели выбери проект → **New project / Создать проект**. Назови его `Forma personal` и выбери созданный проект.
3. Открой **APIs & Services → Library / API и сервисы → Библиотека**. Найди **Google Drive API**, открой его и нажми **Enable / Включить**. Для обычного личного использования Drive API платная подписка не нужна.
4. Открой **Google Auth Platform / Платформа Google Auth**. Если предлагается **Get started / Начать**, заполни название приложения `Forma`, почту поддержки и контактную почту.
5. В **Audience / Аудитория** выбери **External / Внешние пользователи**. Для первого запуска в режиме **Testing / Тестирование** добавь свою Google-почту в **Test users / Тестовые пользователи**.
6. В **Data Access / Доступ к данным → Add or remove scopes** добавь:
   - `openid`
   - `https://www.googleapis.com/auth/userinfo.email` (в запросе приложения используется эквивалент `email`)
   - `https://www.googleapis.com/auth/drive.appdata`

Нужен именно `drive.appdata`, а не полный доступ `drive`. Это разрешение на закрытые данные приложения; обычные документы в твоём Drive Forma не читает.

## 2. Клиент Windows

1. **Google Auth Platform → Clients / Клиенты → Create client / Создать клиент**.
2. Тип: **Desktop app / Приложение для компьютера**, имя `Forma Windows`.
3. Создай клиент. Сохрани **Client ID** и **Client secret**. Можно скачать JSON и открыть его в текстовом редакторе: поля называются `client_id` и `client_secret` внутри `installed`.
4. Открой Forma на ПК → **Настройки → Google → Настройка проекта Google Cloud**.
5. Вставь **Desktop Client ID** и **Desktop client secret**, затем нажми **Войти через Google**.
6. В браузере выбери свой аккаунт и разреши доступ к данным Forma. После входа вернись в приложение. Если Drive временно недоступен, аккаунт останется подключённым, а изменения — на ПК.

Не создавай Web application или UWP: Forma использует системный браузер и разрешённый Google локальный адрес `127.0.0.1` со случайным портом. Регистрировать вручную постоянный redirect URL для Desktop-клиента не нужно. Client secret и токены сохраняются в защищённом хранилище Windows и не попадают в библиотеку/экспорт.

## 3. Клиент iPhone

**Создавай его в том же проекте `Forma personal`, что и Windows.** Разные проекты создают разные области данных приложения, даже при одной Google-почте.

1. Узнай **Bundle ID установленной Forma**. В исходной IPA это `music.forma.ios`, но Sideloadly может поменять его. Если ты выбирал свой ID в Advanced Options, используй именно этот ID. При автоматическом ID учитывай фактический идентификатор, который сформировал Sideloadly при подписи. При необходимости найди его в `Payload/Forma.app/Info.plist` подписанного файла, поле `CFBundleIdentifier`.
2. **Google Auth Platform → Clients → Create client**.
3. Тип: **iOS**, имя `Forma iPhone`. В поле **Bundle ID** введи идентификатор из предыдущего шага.
4. **App Store ID** не нужен: приложение устанавливается через Sideloadly. **App Check** для этой личной сборки не включай; он требует отдельно настроенного подтверждения приложения/Team ID.
5. Создай клиент и скопируй его **Client ID**. Это второй, отдельный ID; Desktop Client ID на iPhone использовать нельзя. iOS client secret не нужен.
6. На iPhone открой Forma → **Настройки → Синхронизация через Google → Настройка Google Cloud**.
7. Вставь **iOS Client ID**, нажми **Войти через Google** и выбери **тот же аккаунт**, что на Windows.
8. На обоих устройствах нажми **Синхронизировать сейчас**. При первом подключении уникальные местные треки/плейлисты объединяются; при совпадении предпочтений и настроек приоритет у уже опубликованной библиотеки аккаунта.

Обычное обновление подписи Sideloadly не требует нового OAuth-клиента, если Bundle ID остаётся прежним. Если меняешь Bundle ID, создай подходящий iOS-клиент **в том же проекте** и введи новый ID. Forma использует `ASWebAuthenticationSession` и PKCE; пароль вводится только на странице Google.

## 4. Чтобы не входить каждую неделю

Google выдаёт refresh token со сроком **7 дней**, если OAuth-приложение остаётся в режиме **Testing** и запрашивает доступ к Drive. Это отдельное ограничение Google, не срок подписи IPA.

После проверки личного входа в **Audience / Аудитория** переведи OAuth-приложение в **In production / В рабочий режим** с помощью **Publish app**. Если консоль требует дополнительных сведений, выполни её требования. Используемые `openid`, `email` и `drive.appdata` относятся к базовым/несекретным разрешениям; Forma не запрашивает чтение всех файлов Drive. После смены режима нажми «Войти повторно» в Forma, чтобы получить новый refresh token. Доступ всё равно может быть отозван вручную или политикой Google/рабочего аккаунта.

## Как работает обмен

- Синхронизируются YouTube-метаданные, плейлисты, лайки, дизлайки, скрытые треки, история с контекстом обучения, настройки Пульса и числовые признаки звучания.
- Музыкальные файлы, скачанные записи, локальные пути, API-ключи, громкость и палитра остаются на устройстве.
- Каждое устройство пишет свой файл в закрытом `appDataFolder`. Изменения сливаются по отдельным записям, а удаления сохраняются как отметки. Одновременные изменения разных плейлистов и предпочтений не заменяют всю библиотеку снимком с одного устройства.
- Изменения сохраняются локально до обращения к сети. При сетевой ошибке срабатывает задержка повторных запросов. Воспроизведение не ждёт облако.
- Автоматический обмен происходит, когда приложение работает и есть интернет; после запуска/возвращения приложение проверяет накопленные изменения. iOS не гарантирует обмен при полностью закрытой Forma. Музыка продолжает играть в фоне независимо от синхронизации.
- Выход из Google оставляет библиотеку на устройстве. При выборе другого аккаунта эта местная библиотека будет объединена с ним; при совместном использовании телефона учитывай это перед сменой аккаунта.
- В обычном интерфейсе Drive файлы не видны. Управлять доступом можно в [подключённых сервисах Google](https://myaccount.google.com/connections). Удаление скрытых данных Forma в настройках Drive удаляет облачную копию, но не библиотеку на устройствах.

## Если вход или обмен не работает

| Ошибка | Что проверить |
| --- | --- |
| `access_denied`, аккаунт не разрешён | Добавь именно эту почту в Test users, если проект в Testing. |
| `redirect_uri_mismatch` | На Windows нужен Desktop-клиент; на iPhone — iOS-клиент. Не Web application. Проверь, что ID скопирован целиком. |
| `invalid_client` | Перепутаны типы клиента или Desktop client secret. На iOS secret не вводится. |
| `403` от Drive | Включён ли Google Drive API в этом проекте; выдан ли `drive.appdata`; нет ли ограничений корпоративного аккаунта. |
| Два устройства вошли, библиотека разная | Один аккаунт **и один Google Cloud проект**, затем ручной обмен на обоих устройствах. |
| Доступ истёк через неделю | Переведи проект из Testing в Production и войди заново. |
| Нет ответа через мобильную сеть/VPN | Нужен доступ к `accounts.google.com`, `oauth2.googleapis.com`, `openidconnect.googleapis.com`, `www.googleapis.com`. При работающем VPN менять его состояние не нужно; проверь доступность этих адресов через него. |

Интеграция проверена сборками, тестами слияния и контролируемыми HTTP-ответами. Полный вход и обмен с реальным Google-аккаунтом нужно проверить после создания твоего проекта; чужие токены или фиктивный Client ID приложение не использует.

Официальные источники: [OAuth для iOS/Desktop](https://developers.google.com/identity/protocols/oauth2/native-app), [Drive appDataFolder](https://developers.google.com/workspace/drive/api/guides/appdata), [сроки refresh token](https://developers.google.com/identity/protocols/oauth2#expiration).
