# Google-синхронизация: архивная информация

Интеграция относилась к Windows 1.8.0 / iOS 1.2.0 и удалена в Windows 1.9.0 / iOS 1.3.0 по запросу владельца. Создавать OAuth-проект больше не нужно.

Используй **[обмен по Wi-Fi с просмотром и подтверждением](WIFI_SYNC.md)**. При обновлении сохраняется локальная библиотека и удаляются локальные Google-реквизиты. Приложение не обращается к Drive и не удаляет ранее созданные облачные файлы. При необходимости прежний доступ можно отозвать в [подключённых сервисах Google](https://myaccount.google.com/connections).
