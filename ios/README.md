# Forma для iOS — заготовка 0.1

Нативный проект **SwiftUI + AVPlayer**, iOS 17+, iPhone и iPad. Источник музыки — YouTube/YouTube Music через интернет. Подписка, аккаунт, обязательный сервер и заранее скачанная библиотека в этой архитектуре не требуются.

**Это исходники заготовки, а не готовая проверенная IPA.** Код подключает настоящее получение потоков через [YouTubeKit](https://github.com/alexeichhorn/YouTubeKit); тестовые песни не подставляются вместо YouTube. Текущая работоспособность этого неофициального получения потоков и фонового воспроизведения на iPhone ещё требует проверки. YouTube может отказать запросу или изменить протокол. Публикация такого клиента в App Store не гарантируется.

## Что включено

- Тёмный SwiftUI-интерфейс со стеклянными панелями, мягкими градиентами, главной страницей, поиском, любимым, мини-плеером и раскрывающимися настройками Пульса.
- Поиск YouTube Music по названию и артисту, задержка 350 мс, отмена устаревших результатов. Если поиск не отвечает, доступен ввод ссылки YouTube в разделе поиска.
- Нативное потоковое воспроизведение AAC/M4A. Получение URL выполняется на телефоне: `YouTubeStreamResolver` использует vendored YouTubeKit под MIT; внешний fallback-сервер явно выключен.
- `UIBackgroundModes = audio`, аудиосессия `.playback`, обработчики системных кнопок и экран блокировки с названием, артистом и обложкой. Интерфейс не ставит плеер на паузу при уходе в фон. Обрабатываются звонки, отключение наушников и сброс аудиосистемы.
- Очередь, переключение, перемотка, громкость; короткий кэш потоков, сброс при смене сети и одна повторная попытка обновить URL при ошибке. Следующий URL подготавливается во время текущего воспроизведения, если известен кандидат. Гарантии бесшовного воспроизведения нет; системную работу цепочки треков при блокировке нужно проверить на устройстве.
- Начальное Swift-ядро Пульса: любимое и плейлистные опоры, дослушивания/пропуски, затухание истории, текущая сессия, разнообразие артистов, новые открытия и интервалы повторов. Шесть подборок по настроению используют общий профиль. Ошибка воспроизведения не обучает отрицательный вкус; перемотка не увеличивает прослушанные секунды.
- Локальное сохранение **метаданных, любимого и истории**, атомарная запись, резервная копия и сохранение повреждённого файла при восстановлении. Это не локальный источник музыки. Временные URL потоков не записываются в профиль. Есть экспорт JSON.

Мобильное ядро пока меньше настольного: полного переноса Beta-модели обратной связи, многокластерного алгоритма и всех фильтров Forma 1.3 нет. UI создания плейлистов, импорт Яндекса, синхронизация с Windows, восстановление позиции/очереди после завершения процесса и скачивание музыки в эту заготовку не включены. Формат мобильной библиотеки отдельный; экспорт Windows напрямую импортировать нельзя.

Настроения и жанры YouTube используются как **слабый контекст запроса**, а не как результаты анализа аудио. Если подборка пуста, интерфейс сообщает об этом.

## Открыть и запустить

Нужны **Mac, Xcode 16+ и iOS 17+**. Дополнительный генератор проекта устанавливать не нужно: `.xcodeproj` уже включён.

1. Открой `ios/Forma.xcodeproj`.
2. Выбери схему **Forma** и симулятор iPhone либо подключённый iPhone.
3. Для телефона в **Signing & Capabilities** выбери свой Team и уникальный Bundle Identifier. Учётная запись Apple нужна для подписи установки, а не для музыкальной подписки. У бесплатной персональной подписи есть ограничения и срок действия.
4. Нажми Run. Открой «Поиск», найди трек или вставь ссылку кнопкой с цепочкой. Разрешения Apple Music не запрашиваются.
5. Сохраняй любимое сердечком и обнови подборки на главной.

Для первого проигрывания дождись, пока музыка действительно начнёт звучать, затем проверяй блокировку. В симуляторе можно проверить интерфейс и сборку; энергосбережение, наушники, звонки и фон нужно проверять на физическом устройстве. Иконка AppIcon пока является стандартным пустым слотом проекта; перед распространением нужно добавить собственное изображение 1024×1024.

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `Forma/YouTubeCatalog.swift` | Анонимный поиск/связанные треки, отдельный сетевой клиент |
| `Forma/YouTubeStreamResolver.swift` | Адаптер открытого YouTubeKit, временные URL и обновление |
| `Forma/PlaybackController.swift` | Нативный плеер, аудиосессия, системное управление, очередь и журнал потребления |
| `Forma/AppModel.swift` | Библиотека и общий профиль рекомендаций; UI не владеет аудиопроцессом |
| `Packages/FormaCore` | Независимые модели, парсер, Пульс, правила URL/кэша и файловое хранение |
| `Vendor/YouTubeKit` | Закреплённый снимок открытой библиотеки с авторством и лицензиями |

Плеер принадлежит `AppModel`, который живёт на уровне приложения, а не страницы. Для будущего Android-порта заменяются платформенный плеер и адаптер потоков; интерфейс и Swift-код не являются готовым Android-приложением.

## Проверки

```sh
swift test --package-path ios/Packages/FormaCore
python3 ios/Scripts/generate_project.py --check
xcodebuild -project ios/Forma.xcodeproj -scheme Forma \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath ios/.derived-data CODE_SIGNING_ALLOWED=NO build
```

18 тестов FormaCore прошли в Linux со Swift 6.1.2: парсинг того же проверочного ответа YouTube Music, что использует Windows-проект; публичные ссылки; прослушивания/пропуски; общие подборки; затухание сессии; исключения; сохранение небольших интересов; счётчик времени; истечение URL и восстановление библиотеки. Синтаксис Swift-файлов приложения проверен компилятором. Это **не** сборка с iOS SDK и **не** проверка живого YouTube.

GitHub Actions `.github/workflows/ios.yml` запускает тесты ядра и настоящую сборку с Xcode на macOS. Артефакт **Forma-iOS-Simulator** предназначен только для симулятора: его нельзя установить на iPhone как IPA. До получения результата workflow сборка с iOS SDK считается непроверенной.

После добавления Swift-файлов/ресурсов обнови проект:

```sh
python3 ios/Scripts/generate_project.py
```

При проверке телефона: воспроизведение минимум трёх треков подряд с заблокированным экраном, ручное переключение с наушников, звонок, отключение Bluetooth, переход Wi-Fi → мобильная сеть, ошибка/истечение потока без негативного события в профиле. После принудительного завершения приложения продолжение музыки не обещается.
