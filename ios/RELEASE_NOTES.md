# Forma iOS 1.6.0

- Космическая тема с фиолетово-чёрным фоном и падающими звёздами. Пульс — отдельная галактика без прямоугольной плашки. Иконка приложения совпадает с галактической иконкой Windows.
- Полупрозрачные поверхности, короткие подписи и настройка «Навигация только иконками». Нижние вкладки сохраняют названия для VoiceOver. При крупном тексте подборки переходят в одну колонку, кнопки мини-плеера — в отдельную строку.
- Дизлайк текущего трека сразу переключает на следующий, без дополнительного сигнала пропуска. Отмена оценки и оценка другого трека не прерывают музыку.
- Личная галактика различает Пульс и подборку по настроению/плейлисту. Её кнопка приостанавливает и продолжает личный Пульс; из подборки запускает личный заново.
- Поиск скрывает результаты предыдущего запроса. У полного плеера есть кнопка закрытия, громкость сохраняется между запусками. Ошибка открытия библиотеки получает постоянное уведомление с повторной попыткой. Сообщения об ошибках доступны и в модальных экранах.
- Декоративное движение изолировано от плеера, останавливается вне активного экрана и учитывает «Уменьшение движения». Его можно отключить в оформлении. Системное уменьшение прозрачности делает панели непрозрачными.

Рекомендации, шесть русских подборок, подготовка до трёх треков на мобильной сети, фоновое воспроизведение и подтверждаемый Wi-Fi обмен сохранены. Windows менять не нужно.

IPA без подписи, iOS 17+ / arm64, сборка 14. Установи поверх прежней Forma с теми же Apple ID и **фактическим Bundle ID** в Sideloadly; не удаляй приложение. [Установка с Windows](https://github.com/Astronomial/music/blob/main/ios/INSTALL_WINDOWS.md).

Проверки используют нативный симулятор, AVFoundation, контролируемое аудио и сетевые ответы. Живой YouTube, физический iPhone и реальный VPN требуют проверки на устройстве.
