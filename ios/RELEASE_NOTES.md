# Forma iOS 1.4.2

- Начало трёх следующих треков готовится параллельно без прежней задержки в полсекунды. Медленный второй трек не блокирует подготовку третьего.
- При выборе ещё загружающегося трека переносится тот же AVPlayer/аудиоэлемент с накопленными данными. Старая задача подготовки не может очистить активный плеер после переключения.
- Приоритет текущего трека отменяет ненужные запросы, сохраняя готовые свежие URL других треков.
- Для медленного запроса с кешированным контекстом резервный WEB-путь запускается через 250 мс. Быстрый ответ отменяет резервный запрос до его начала.
- EMBED-клиенты используют фактический Bundle ID приложения вместо идентификатора постороннего сайта. Нативный путь iOS сохраняет собственные заголовки.
- Подготовка до трёх треков работает через мобильную сеть, с VPN и при включённом режиме экономии данных; пауза, фон, дизлайки, Пульс и подтверждаемый Wi-Fi обмен сохранены.

IPA без подписи, iOS 17+ / arm64, сборка 12. Установи поверх прежней Forma с теми же Apple ID и фактическим Bundle ID в Sideloadly. Не удаляй приложение. [Установка](https://github.com/Astronomial/music/blob/main/ios/INSTALL_WINDOWS.md).

Автоматические проверки используют контролируемые ответы YouTube и настоящее AVFoundation с медленным HTTP-аудио. Готовый буфер и холодный сетевой запуск проверяются отдельно. Мгновенный запуск любого неподготовленного ролика не гарантируется: он зависит от доступности YouTube, сети и VPN. Физический iPhone и живой сервис требуют проверки на устройстве.
