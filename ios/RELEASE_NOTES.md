Forma iOS 1.9.2 — исправлено подключение к ПК.

- Проверка нескольких локальных адресов с закреплённым сертификатом ПК, включая запасной адрес при недоступности первого.
- Маршрут мобильного интернета/VPN больше не блокирует отдельно доступную Wi-Fi сеть. Сеанс обмена запрещает передачу через мобильную сеть.
- Повторное подключение к тому же ПК сохраняет действующий токен и ожидающий подтверждения обмен.
- В настройках есть «Проверить соединение», подробная ошибка и переход к разрешениям iPhone. USB используется для установки, библиотека передаётся по локальной сети.
- Изменения применяются после подтверждения на одном устройстве. Подготовка трёх треков, Пульс и фоновое аудио сохранены.

Обнови ПК до Windows 1.17.1. IPA для iOS 17+, arm64, сборка 20. Установи поверх прежней Forma с теми же Apple ID и Bundle ID Sideloadly.
