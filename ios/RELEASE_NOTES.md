# Forma iOS 1.3.0

- Google удалён. Обмен с Windows 1.9.0 снова по Wi-Fi: сначала просмотр изменений, затем «Применить на обоих устройствах» на ПК или телефоне. Одного подтверждения достаточно. Без него библиотека не меняется; новые пакеты не создаются автоматически. Решение и получение сохраняются после перезапуска, повторные запросы не дублируют перенос.
- По умолчанию заранее готовится начало до трёх следующих треков Пульса и очереди, включая мобильный интернет и включённый режим экономии данных iOS. Первый трек находится в основной очереди, ещё два буферизуются без звука. Готовый элемент используется при выборе трека без повторного получения потока. В настройках можно вручную выбрать подготовку только следующего трека.
- Устаревшие буферы сбрасываются при смене маршрута/VPN и аудиосервиса; ошибки подготовки не отменяют текущую музыку. Подготовка запускается после старта текущего аудио и готовности ближайшего следующего трека.
- Сохранены дизлайки, анализ звучания, обучение Пульса, фоновая очередь, системное управление и расположение мини-плеера над вкладками.

IPA без подписи, iOS 17+ / arm64, сборка 9. Установи поверх прежней Forma с теми же Apple ID и фактическим Bundle ID в Sideloadly, включая ранее выбранный вручную идентификатор. Не удаляй приложение перед обновлением. [Установка](https://github.com/Astronomial/music/blob/main/ios/INSTALL_WINDOWS.md) · [Обмен по Wi-Fi](https://github.com/Astronomial/music/blob/main/docs/WIFI_SYNC.md).

Предварительная подготовка ускоряет уже готовые треки. Произвольный новый результат поиска всё ещё требует получения потока и зависит от доступности YouTube/VPN. Нативные проверки используют контролируемое HTTP-аудио, а не живой YouTube.
