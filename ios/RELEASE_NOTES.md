Forma iOS 1.11.2 — исправления рекомендаций после аудита ECC.

- Готовая очередь Пульса перепроверяет жанры исходных треков по актуальной библиотеке: устаревшие сведения больше не подтверждают неподходящую музыкальную связь.
- При выборе из кеша обновляются соответствие вкусу, язык, жанр, исполнитель, звучание и признаки обучения. Реакция на трек обучает модель на актуальных данных.
- Повторная проверка языка использует заранее подготовленные регулярные выражения и создаёт меньше нагрузки при выборе кандидатов.
- Сохраняются поиск свежих релизов близких артистов, полная ротация лайков и плейлистов в знакомых 30%, фоновое аудио, предзагрузка трёх треков и обмен с ПК после подтверждения.

iOS 17+, arm64, сборка 25. Установи поверх прежней Forma с теми же Apple ID и Bundle ID, чтобы сохранить библиотеку; актуальная версия ПК — Windows 1.19.2.

Проверки релиза: полный FormaCore, регрессии жанровых связей и обучения, лимиты времени ранжирования, контролируемые ошибки загрузки аудио, сборки Simulator/iPhone и нативный сценарий фоновой очереди и защищённой синхронизации. Они выполняются перед публикацией. Живой YouTube на физическом iPhone и личный вкус пользователя эти проверки не измеряют.

Применён ECC verification-loop. Закрытые модели и данные Spotify не используются.
