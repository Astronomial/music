# Установка Forma на iPhone с Windows

Поддерживаются **iOS 17 и новее**, включая iOS 18; iPhone и iPad. Музыкальная подписка не нужна. Для установки требуется подпись твоим Apple ID: бесплатная личная подпись обычно действует **7 дней**, затем приложение нужно подписать повторно.

## Скачать

- [Forma iOS 1.6.0 — IPA для подписи](https://github.com/Astronomial/music/releases/download/ios-v1.6.0/Forma-iOS-1.6.0-unsigned.ipa).
- [Контрольная сумма IPA](https://github.com/Astronomial/music/releases/download/ios-v1.6.0/Forma-iOS-SHA256SUMS.txt).
- [Forma 1.14.0 для Windows — синхронизация и новый Пульс](https://github.com/Astronomial/music/raw/refs/heads/main/downloads/Forma-1.14.0-Windows-x64.exe).
- [Sideloadly для Windows — официальный сайт](https://sideloadly.io/).

IPA собрана для настоящего устройства, но не подписана сертификатом Apple. Простое открытие файла на iPhone её не установит. Windows-приложение можно обновить запуском новой portable-сборки: прежняя библиотека сохраняется.

## Что изменилось в 1.6.0

Космическая тема: фиолетово-чёрный фон, падающие звёзды, галактика Пульса без прямоугольной плашки и новая иконка. Панели полупрозрачны, подписи короче. **Настройки → Оформление → Навигация только иконками** скрывает подписи нижних вкладок; названия для VoiceOver сохраняются. Движение можно отключить там же; системное уменьшение движения учитывается.

Дизлайк текущего трека сразу включает следующий и учитывается один раз. Отмена дизлайка и оценка другого трека не прерывают музыку. Плеер остаётся выше навигации; при крупном системном тексте его кнопки переносятся в отдельную строку. Полный плеер получил явную кнопку закрытия. Громкость сохраняется на iPhone. Поиск скрывает устаревшие результаты при новом запросе.

Подборки, подготовка до трёх треков, фон, VPN и подтверждаемый Wi-Fi обмен сохранены. Windows обновлять для этого выпуска не требуется. При установке поверх используй прежние Apple ID и **фактический Bundle ID**, не удаляй Forma.

## Установить через USB

1. Установи Sideloadly с его официального сайта. Установи необходимые компоненты Apple/iTunes/iCloud по инструкции на этом же сайте; Sideloadly рекомендует настольные версии Apple, если компоненты из Microsoft Store вызывают ошибки.
2. Подключи разблокированный iPhone к Windows по USB. Подтверди **«Доверять этому компьютеру»** на телефоне и убедись, что он появляется в списке устройств Sideloadly.
3. Перетащи `Forma-iOS-1.6.0-unsigned.ipa` в окно Sideloadly. Выбери iPhone и режим **Apple ID Sideload**. При первой установке можно оставить автоматический выбор Bundle ID. При обновлении используй те же Apple ID и Bundle ID, с которыми уже установлена Forma. Если ранее вводил свой идентификатор, снова укажи его в Advanced Options, сняв галочку Use automatic bundle ID.
4. Введи Apple ID непосредственно в Sideloadly и нажми **Start**. Подтверди двухфакторную проверку, если её запросит Apple. Пароль и код вводятся только в установленной программе, их не нужно отправлять в чат или записывать в Forma.
5. После установки открой на iPhone **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включи его и подтверди перезапуск. Если пункт ещё не появился, закончи первую установку и переподключи телефон.
6. При запросе доверия открой **Настройки → Основные → VPN и управление устройством**, выбери профиль своей учётной записи и подтверди доверие. Для проверки подписи нужен интернет.
7. Открой Forma. Найди трек по названию или артисту, либо нажми кнопку ссылки в поиске и вставь YouTube URL. Дождись начала звука; после этого можно свернуть приложение или заблокировать экран.

Меню могут немного отличаться в разных языках iOS. Бесплатная подпись обычно ограничена тремя приложениями и сроком 7 дней. Для обновления подписи снова подключи телефон и установи IPA поверх прежней копии с тем же идентификатором: не удаляй приложение, иначе его локальная библиотека может потеряться. Автоматическое обновление через Wi-Fi настраивается отдельно в Sideloadly. Платный Apple Developer для базовой установки не обязателен.

## Подключить библиотеку к ПК

1. Обнови ПК до **1.11.0**, iPhone до **1.6.0**. Подключи их к одному домашнему роутеру; ПК может использовать Ethernet.
2. На ПК: **Настройки → iPhone и ПК · Wi-Fi → Подключить iPhone**. Разреши Forma доступ к частной сети в брандмауэре. Скопируй код подключения.
3. На телефоне: **Настройки → Синхронизация с ПК**, вставь код → **Подключить ПК**. Разреши iOS доступ к локальной сети.
4. Проверь подготовленные изменения **На ПК** и **На iPhone**, нажми **Применить на обоих устройствах** на любом одном устройстве. Можно отклонить пакет.
5. Для следующего переноса нажми **Подготовить обмен** на iPhone и снова подтверди просмотренный пакет. Подключение и локальные правки сами по себе перенос не запускают.

[Подробная инструкция, содержание пакета и решение проблем](../docs/WIFI_SYNC.md). ПК нужен для обмена, но не для самого прослушивания. Общая сеть нужна только для синхронизации; музыка и подготовка трёх следующих треков работают также через мобильный интернет.

## Пульс и фоновое воспроизведение

В раскрывающихся настройках Пульса можно выбрать направления, настроение, энергию, вокал, открытия, разнообразие артистов, интервал повторов, предпочитаемых/исключённых исполнителей и плейлисты, которые обучают вкус. Кнопка **«Больше новых имён»** увеличивает разнообразие. Жанры и характер музыки частично определяются по поисковому контексту, поэтому это предпочтения с ограниченной точностью.

Плеер использует нативные `AVQueuePlayer` и аудиосессию `.playback`. Начало до трёх следующих треков готовится заранее; дополнительные буферы не воспроизводятся вслух. Экран блокировки и системный плеер позволяют ставить на паузу, переключать и перематывать. ПК после переноса библиотеки не требуется для самого прослушивания.

YouTube должен быть доступен на телефоне. Получение потоков неофициальное, выполняется на устройстве и может перестать работать при изменениях сервиса; вход и подписка не используются. После принудительного закрытия приложения смахиванием музыка прекращается. Офлайн-прослушивание YouTube в этой версии не предусмотрено.

## Если что-то не работает

- **IPA не устанавливается:** проверь USB-доверие, компоненты Apple, режим Apple ID Sideload, лимит личных приложений и интернет для подписи. Файл предназначен для подписи, а не для установки напрямую из Safari.
- **Приложение перестало открываться через неделю:** обнови личную подпись через Sideloadly поверх прежнего приложения.
- **Ошибка Apple 9400 / App ID is not available:** в Sideloadly открой Advanced Options, сними Use automatic bundle ID и введи уникальный идентификатор, например `com.astronomial.forma.personal826491`. При последующих обновлениях сохраняй этот же идентификатор, иначе получится отдельная копия приложения.
- **Старая версия ПК не подключается:** обнови Windows до 1.11.0 и iOS до 1.6.0, проверь, локальную сеть, разрешение Forma в брандмауэре, разрешение iOS «Локальная сеть», срок кода и текущий IP ПК. Гостевая Wi-Fi сеть с изоляцией клиентов может блокировать соединение.
- **Трек не запускается:** попробуй другое видео, поиск или прямую ссылку. Сообщение об отсутствии аудиопотока означает, что YouTube не предоставил поддерживаемый URL; повторная подпись приложения это не исправляет.
- **Фон на конкретном iPhone:** проверь минимум три автоматических перехода с заблокированным экраном, системную паузу/возобновление и смену Wi-Fi на мобильную сеть. CI проверяет реальную нативную очередь в фоне симулятора на тестовом аудио; доступ к живому YouTube и блокировка физического устройства требуют отдельной проверки.
