# Forma — музыка в твоём ритме

Windows-приложение с каталогом Audius, персональной волной, плейлистами и локальным воспроизведением. Интерфейс на русском, тёмная минималистичная тема, спокойный зелёный акцент.

**[Скачать готовое приложение для Windows x64](https://github.com/Astronomial/music/raw/refs/heads/main/downloads/Forma-1.0.0-Windows-x64.exe)** — без установки и Node.js. Проверенная сборка 1.0.0, около 82 МБ. [Контрольная сумма](downloads/SHA256SUMS.txt).

![Интерфейс Forma — проверочный каталог](artifacts/forma-home.png)

## Запуск на Windows

1. Открой `Forma-1.0.0-Windows-x64.exe`. Это готовая portable-сборка для Windows 10/11 x64; Node.js и терминал не нужны. Первый запуск может занять несколько секунд, пока распаковывается приложение.
2. Выбери любимые жанры. Приложение загрузит музыку из Audius.
3. Нажми «Слушать волну». Сохраняй понравившиеся треки сердечком и добавляй их в плейлисты через меню `…`.
4. Для скачивания нажми стрелку вниз у трека. В разделе «Скачанное» можно слушать музыку без интернета и удалить файл через меню трека.

В готовом комплекте — portable `.exe`. Обычный установщик `Forma-1.0.0-Setup.exe` предусмотрен командой `npm run dist:installer`; его можно собрать на Windows из исходников. В этой Linux-среде сборка NSIS-установщика остановилась на ошибке Wine, поэтому незавершённый установщик не включён в комплект.

Сборки не имеют сертификата издателя. Windows SmartScreen может показать предупреждение о неизвестном издателе. Проверяй происхождение файла; SHA-256 приведены в `release/SHA256SUMS.txt`.

## Что реализовано

- Поиск треков и исполнителей Audius; публичные API-узлы с переключением при сбое.
- Непрерывная персональная волна с пересчётом следующего трека после каждого сигнала.
- Любимые треки, создание/переименование/удаление плейлистов, добавление и удаление треков.
- Четыре персональные подборки: daily mix, фокус, электронная музыка после полуночи и открытия. Это подборки Forma, которые пересчитываются по профилю.
- Очередь, пауза, перемотка, громкость, повтор трека, перемешивание обычной очереди, системные мультимедийные кнопки.
- Скачивание, прогресс/отмена, локальное воспроизведение с перемоткой, восстановление после перезапуска.
- Офлайн-режим: волна и поиск работают только по скачанным трекам.
- Настройка доли открытий, объяснения рекомендаций, скрытие треков, сброс истории, экспорт библиотеки.

Горячие клавиши: `Пробел` — пауза/воспроизведение; `Ctrl+→` — следующий; `Ctrl+←` — предыдущий. Ввод и модальные окна исключены из этих обработчиков.

## Рекомендации — основной акцент

Это собственный локальный алгоритм, ориентированный на сочетание персонального вкуса, нескольких музыкальных интересов и новых открытий. Он не использует закрытую модель Spotify и не обещает одинакового качества с сервисом, который обучается на поведении миллионов пользователей.

**Основа профиля:** жанр, настроение, теги, исполнитель; темп используется при наличии BPM. Сходство с отдельными сохранёнными треками помогает сохранять несколько разных направлений вкуса вместо одного усреднённого профиля.

**Сигналы:**

| Действие | Влияние |
| --- | --- |
| Добавить в любимое | +5 к постоянному профилю трека |
| Добавить в плейлист | +3 за плейлист; суммарный постоянный вес ограничен 9 |
| Прослушать не менее 80% | +1.5 |
| Прослушать 50–80% | +0.5 |
| Пропустить до 30 секунд и до 25% длительности | −2.5 |
| Пропустить до 65% | −0.8 |
| Переключить после 65% | Без отрицательного сигнала |
| Не рекомендовать трек | Исключение из рекомендаций до отмены |
| Ошибка воспроизведения/сети | Без отрицательного сигнала |

Пропуски считаются по фактически прослушанным секундам, а не по положению после перемотки. Неявные сигналы ослабевают вдвое каждые 30 дней. Повторные сигналы одного трека ограничены диапазоном −7…+4. Один пропуск не должен вычёркивать целый жанр: влияние отрицательного профиля растёт по мере накопления свидетельств. При закрытии приложение сохраняет текущую сессию.

**Поиск кандидатов:** тренды, underground, популярное и недавнее в любимых жанрах, треки знакомых исполнителей, поиск по значимым тегам. Обработка пакетами по три запроса уменьшает нагрузку на публичные узлы. Недоступные и закрытые треки фильтруются.

**Ранжирование:** сочетание глобального профиля, сходства с отдельными интересами, текущей сессии, отрицательных сигналов и управляемой доли новизны. Популярность имеет небольшой вес. Затем применяется MMR и штрафы за повтор исполнителя. Треки, прозвучавшие в последние два часа, исключаются из волны. При нехватке кандидатов приложение обновляет каталог; если новых треков не осталось, сообщает об этом, а не повторяет одни и те же треки.

Офлайн-волна использует тот же алгоритм на скачанных файлах. При очень маленькой библиотеке возможности разнообразия ограничены.

## Audius и скачивание

Используются REST API Audius и каталог независимых исполнителей: он отличается от каталога Spotify/Яндекс Музыки. По умолчанию приложение обращается к публичным узлам с `app_name=FormaMusic`. Если узел требует API-ключ, в настройках можно указать ключ бесплатного плана Audius.

Оригинальный файл скачивается через `/tracks/{id}/download`, только если API разрешает свободное скачивание и не указывает условия доступа. Приложение повторно проверяет актуальную метаинформацию перед загрузкой. Закрытые, платные или требующие подписки/других условий загрузки не обходятся. Поэтому возможность скачать есть у части каталога.

Поддерживаются MP3, WAV, FLAC, Ogg и M4A, если формат декодируется Chromium/Electron. Ограничение: 350 МБ на файл, 10 ГБ на библиотеку, до двух одновременных загрузок. Перед добавлением в библиотеку проверяются тип аудиофайла и завершённость загрузки. Отменённые и оборванные файлы не появляются как скачанные.

Библиотека хранится в `%APPDATA%\Forma\library.json`, музыка — в `%APPDATA%\Forma\Music`. В portable-версии данные также лежат в профиле пользователя и сохраняются между запусками. Кнопка «Открыть папку» показывает точное расположение. JSON записывается атомарно, предыдущая версия остаётся в `.bak`. Рекомендательный профиль не отправляется в Audius; запросы к API и аудио выполняются для поиска/воспроизведения. Необязательный API-ключ сохраняется локально и исключается из экспорта библиотеки.

## Разработка

Нужны Node.js 22.12+ (рекомендуется 24) и npm.

```powershell
npm ci
npm run desktop
```

Команды:

```powershell
npm run dev             # браузерный предпросмотр
npm run build           # production UI
npm test                # алгоритм, API-адаптер, файловое хранение
npm run test:ui         # нужен Chromium и npm run dev в другом терминале; CHROMIUM_PATH задаёт путь браузера
npm run test:desktop    # настоящий Electron; в Linux нужен DISPLAY/Xvfb
npm run dist:win        # portable Windows x64
npm run dist:installer  # установщик NSIS
```

Браузерный предпросмотр показывает интерфейс, поиск и рекомендации; загрузка на диск и нативные функции доступны в Electron. Никакие тестовые треки не включены в приложение. Снимок `artifacts/forma-home.png` сделан с проверочным каталогом.

Структура: `src/core/recommender.mjs` — алгоритм; `src/core/audius.mjs` — API и подбор кандидатов; `electron/offline.cjs` — загрузки и выдача локального аудио с HTTP Range; `electron/storage.cjs` — запись библиотеки; `src/App.jsx` и `src/styles.css` — интерфейс.

## Проверено и ограничения проверки

- 16 автоматических проверок алгоритма, API-адаптера и файлового хранения.
- Сценарии интерфейса с контролируемыми ответами Audius и тестовым аудио: первый запуск, каталог, сохранения, плейлисты, поиск, волна, пропуск, пауза, офлайн-режим, перезапуск, размеры окна.
- Нативный Electron: изоляция renderer/preload, IPC-загрузка, локальный аудиопротокол, перемотка, сохранение при закрытии и воспроизведение после перезапуска.
- Windows-файлы собраны из production-версии интерфейса. Запуск именно под Windows здесь не проверен: среда сборки работает на Linux.
- Среда сборки запрещает исходящие соединения с Audius. Живой каталог, фактическая доступность конкретных API-узлов и сетевое воспроизведение требуют проверки с Windows-компьютера, имеющего доступ к Audius. Это явно отделено от проверок с тестовыми ответами.

Документация: [Audius API](https://docs.audius.co/api/), [Audius tracks](https://docs.audius.co/sdk/tracks/).
